# Desarrollo Colaborativo del Proyecto Biblioteca Virtual

## Organización del Trabajo

Para el desarrollo del proyecto **Biblioteca Virtual**, se utilizó Github y GitHub desktop como herramientas de control de versiones y trabajo colaborativo. El equipo organizó las actividades mediante la creación de **Issues**, permitiendo asignar responsabilidades específicas a cada integrante y realizar un seguimiento del progreso de las tareas.

## Uso de Ramas (Branches)

Para evitar conflictos durante el desarrollo, cada integrante trabajó en una rama independiente:

* `feature-diseno`
* `feature-contactos`
* `feature-libros`
* `feature-login`

Cada rama permitió desarrollar nuevas funcionalidades sin afectar el código principal almacenado en la rama `main`.

---

## Pull Requests

Una vez finalizada cada tarea, los integrantes realizaron un **Pull Request (PR)** para solicitar la incorporación de sus cambios a la rama principal.

Durante esta etapa se revisó:

* Correcto funcionamiento del código.
* Cumplimiento de los requisitos del proyecto.
* Organización y calidad del código.
* Compatibilidad con las demás funcionalidades.

---

## Merges

Después de la revisión y aprobación de los Pull Requests, se realizaron los **Merges** correspondientes para integrar los cambios en la rama `main`.

Los merges permitieron consolidar:

* El diseño principal de la Biblioteca Virtual.
* El módulo de contactos.
* El catálogo de libros.
* El sistema de inicio de sesión.

---

## Beneficios del Trabajo Colaborativo

El uso de GitHub permitió:

* Mejor organización del proyecto.
* Distribución eficiente de tareas.
* Seguimiento del avance mediante Issues.
* Control de cambios a través de ramas.
* Revisión de código mediante Pull Requests.
* Integración segura mediante Merges.

Gracias a esta metodología se logró desarrollar el proyecto de manera ordenada, colaborativa y eficiente.
