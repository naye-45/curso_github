# Issues y Projects en GitHub

## ¿Qué son los Issues?

Los **Issues** son herramientas de GitHub que permiten registrar, organizar y dar seguimiento a tareas, errores, mejoras o nuevas funcionalidades dentro de un proyecto.

Se utilizan para documentar problemas encontrados en el software o para proponer cambios y mejoras que deben ser implementados.

### ¿Para qué se utilizan?

* Reportar errores (bugs).
* Solicitar nuevas funcionalidades.
* Registrar tareas pendientes.
* Realizar seguimiento al progreso de una actividad.
* Facilitar la colaboración entre los miembros de un equipo.

### Ejemplo de Issue

**Título:** Validación de campos vacíos en el formulario de inicio de sesión.

**Descripción:** El sistema permite intentar iniciar sesión sin ingresar correo electrónico o contraseña.

**Solución propuesta:** Agregar validaciones que verifiquen que ambos campos contengan información antes de enviar el formulario.

---

## ¿Qué son los Projects?

Los **Projects** son herramientas de gestión de proyectos dentro de GitHub que permiten organizar y supervisar el trabajo utilizando tableros similares a Kanban.

Un Project agrupa múltiples Issues, tareas y actividades relacionadas con un mismo desarrollo.

### ¿Para qué se utilizan?

* Planificar proyectos de software.
* Organizar tareas por estados.
* Dar seguimiento al avance del trabajo.
* Coordinar equipos de desarrollo.
* Priorizar actividades y mejoras.

### Estados comunes de un Project

| Estado      | Descripción                    |
| ----------- | ------------------------------ |
| To Do       | Tareas pendientes por realizar |
| In Progress | Tareas en desarrollo           |
| Review      | Tareas en revisión             |
| Done        | Tareas completadas             |

---

## Relación entre Issues y Projects

Los **Issues** representan tareas individuales, mientras que los **Projects** permiten organizar y gestionar esas tareas dentro de un flujo de trabajo.

Por ejemplo:

### Project: Mejoras del Login Nebula

#### To Do

* Implementar validación de campos vacíos.
* Agregar recuperación de contraseña.

#### In Progress

* Mejorar diseño visual del login.

#### Done

* Implementar opción mostrar/ocultar contraseña.

---

## Ventajas de utilizar Issues y Projects

* Mejor organización del trabajo.
* Seguimiento de tareas y errores.
* Mayor colaboración entre desarrolladores.
* Control del avance del proyecto.
* Facilita la planificación y documentación del software.

## Conclusión

Los **Issues** permiten registrar tareas, errores o mejoras específicas, mientras que los **Projects** ayudan a organizar y gestionar esas tareas dentro de un proyecto de desarrollo. Juntos facilitan la planificación, el seguimiento y la colaboración en equipos de trabajo.
